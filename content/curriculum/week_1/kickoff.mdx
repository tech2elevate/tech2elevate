## Laptop setup

Work through these with your mentor. By the end, you'll have the starter project open in VS Code with a live preview of your page.

<Steps>

### Install Chrome

Download it from [google.com/chrome](https://www.google.com/chrome/). You'll use Chrome to view your website.

### Install Visual Studio Code

Download it from [code.visualstudio.com/download](https://code.visualstudio.com/download) and pick the Windows installer. VS Code is the editor you'll write all your code in. It's free.

### Install the Live Preview extension

Open VS Code, click the **Extensions** icon in the left sidebar, search for **Live Preview** (by Microsoft), and click **Install**. You can also install it from the [marketplace](https://marketplace.visualstudio.com/items?itemName=ms-vscode.live-server). Live Preview shows your page inside VS Code and refreshes it as you type.

### Set up GitHub Copilot

Click the **Copilot** icon at the top of VS Code and sign in with a GitHub account. [Full instructions](https://code.visualstudio.com/docs/copilot/setup) are on the VS Code site.

<Callout type="warning">
  School Gmail accounts at Hiawatha are restricted and can't be used to sign in.
  Students should use a **personal email** to create their GitHub account.
</Callout>

### Download the starter project

[Download the tech2elevate starter as a zip file](/downloads/tech2elevate-starter.zip), then extract it: right-click the zip and choose **Extract All**. In VS Code, choose **File → Open Folder** and pick the extracted `tech2elevate-starter` folder.

### Open the preview

Open `index.html`, then click **Show Preview** in the upper-right corner of the editor. Change some text, and watch the preview update. You're ready for Week 2.

</Steps>
