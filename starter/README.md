# tech2elevate starter

A starting point for building a website with HTML, CSS, and JavaScript.

## Get started

1. [Download the project as a zip file](https://tech2elevate.com/downloads/tech2elevate-starter.zip) and unzip it. On Windows, right-click the file and select **Extract All**. On a Mac, double-click it.
2. If you don't have VS Code, [download and install it](https://code.visualstudio.com/download). It's free.
3. Open the unzipped folder in VS Code.
4. In the Extensions panel, on the left sidebar, install the **Live Preview** extension.
5. Open `index.html` and select **Show Preview** in the upper-right corner of the editor, or right-click the file and select **Show Preview**. Your page opens and updates as you type.
6. Your work saves automatically about a second after you stop typing, so you don't need to save it yourself.

## Project files

- `index.html`: the page content
- `styles.css`: the page's appearance
- `script.js`: the page's behavior

Edit any of these files, and the preview updates to match.

The full setup guide is at https://tech2elevate.com/curriculum/week_1/kickoff.
