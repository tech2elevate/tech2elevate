# tech2elevate

tech2elevate is a non-profit bringing STEM education to underserved communities. We inspire high school students, spark curiosity, and show how technology can be an enabler in their lives.

## The program

- **One-on-one mentoring** by volunteer tech industry professionals
- **8 weeks, 1 hour per week**
- **Web Development fundamentals:** HTML, CSS, and JavaScript

The program was created by a founding team at Target Corporation. We hope it inspires others across the tech industry to start similar programs.

## This repository

This repository holds the content for [tech2elevate.com](https://tech2elevate.com): the program's public site and the learning materials for mentors and students.
